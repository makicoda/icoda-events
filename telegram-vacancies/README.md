# Экспорт маркетинговых вакансий из Telegram-чатов

Скрипты проходят по списку Telegram-чатов/каналов, ищут сообщения-вакансии,
относящиеся к маркетингу, за заданный период (по умолчанию: 1 июня 2026 —
12 августа 2026) и сохраняют их в CSV-таблицу. Есть два варианта — выбери
подходящий.

## Вариант A: без логина, публичное веб-превью (`scrape_public_preview.py`)

Не требует Telegram API credentials и авторизации вообще. Работает через
публичную страницу-превью канала (`https://t.me/s/<username>`). Ограничение:
работает **только для публичных каналов с юзернеймом** — закрытые чаты/группы
по инвайт-ссылке этим способом не читаются (нужен вариант B).

Также у публичных broadcast-каналов веб-превью не показывает автора
конкретного сообщения (только сам текст, дату и ссылки внутри поста) — поле
`poster_contact` в выгрузке этого варианта будет пустым.

### Установка и запуск

```bash
cd telegram-vacancies
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python scrape_public_preview.py
```

Список чатов уже заполнен в `chats.txt`, период — в `config.py`
(`TG_START_DATE`/`TG_END_DATE`, можно переопределить через `.env`, см.
`.env.example`).

Результат — `raw_marketing_vacancies_preview.csv`:

| chat | date | poster_contact | link | text | linked_urls | matched_marketing_keywords | matched_vacancy_keywords |
|---|---|---|---|---|---|---|---|

## Вариант B: через Telegram API (`export_vacancies.py`)

Требует твои личные API credentials и логин в аккаунт, но читает любые чаты,
где ты состоишь (включая закрытые группы), и знает автора каждого сообщения.

### 1. Получить Telegram API credentials

1. Зайди на https://my.telegram.org/apps под своим номером телефона (придёт код в Telegram).
2. Заполни форму создания приложения (App title / Short name — можно любые, например `vacancies-export`; URL можно оставить пустым).
3. После создания получишь **App api_id** и **App api_hash** — это твои личные ключи доступа к Telegram API, никому их не показывай и не публикуй.

### 2. Установка

```bash
cd telegram-vacancies
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и впиши свои `TG_API_ID`, `TG_API_HASH` и `TG_PHONE` (номер в формате `+79991234567`, привязанный к твоему Telegram-аккаунту — скрипт работает от твоего личного аккаунта, а не от бота, иначе история чатов не читается).

### 3. Список чатов

`chats.txt` уже заполнен. Формат — по одному чату на строку:
- юзернейм публичного канала/чата: `@marketing_jobs_ru`
- ссылка-приглашение на закрытый чат: `https://t.me/+AbCdEfGhIjKlMnOp`

Чат должен быть тебе доступен (ты состоишь в нём на своём аккаунте) — иначе Telegram не даст прочитать историю.

### 4. Запуск

```bash
python export_vacancies.py
```

При первом запуске Telegram пришлёт код подтверждения в приложение — введи его в терминале (и пароль двухфакторки, если она включена). Дальше сессия сохраняется в файл `vacancies_session.session`, повторно код вводить не понадобится.

Результат — `raw_marketing_vacancies.csv`:

| chat | chat_title | date | poster_contact | link | text | matched_marketing_keywords | matched_vacancy_keywords |
|---|---|---|---|---|---|---|---|

## Финальная таблица

Оба варианта дают "сырую" выгрузку — то, что однозначно извлекается из
Telegram напрямую. Роль, компанию, гео и контакт для отклика надёжно
регуляркой из свободного текста вакансий не вытащить. Пришли получившийся
CSV-файл обратно в чат — на его основе будут добавлены поля «роль»,
«компания», «гео», «контакт в посте» (контакт для отклика из текста
объявления — может отличаться от `poster_contact`) и «reasoning» (почему
сообщение классифицировано как маркетинговая вакансия), после чего готовая
таблица прикладывается файлом.

## Как настроить фильтры

- Диапазон дат — переменные `TG_START_DATE` / `TG_END_DATE` в `.env` (формат `YYYY-MM-DD`), либо константы в `config.py`.
- Ключевые слова — списки `VACANCY_KEYWORDS` и `MARKETING_KEYWORDS` в `config.py`. Сообщение попадает в таблицу, если содержит хотя бы одно слово из **каждого** списка (это отсекает вакансии не по маркетингу и обсуждения маркетинга без вакансий). Дополняй списки своими словами при необходимости.

## Безопасность

- `.env` и `*.session` — не коммитить в git (уже добавлены в `.gitignore`), в них живут твои личные credentials и авторизованная сессия аккаунта. Для варианта A эти файлы не нужны.
