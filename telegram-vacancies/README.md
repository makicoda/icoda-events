# Экспорт маркетинговых вакансий из Telegram-чатов

Скрипт проходит по списку Telegram-чатов/каналов, ищет сообщения-вакансии,
относящиеся к маркетингу, за заданный период (по умолчанию: с 1 июня текущего
года по сегодня) и сохраняет их в CSV-таблицу.

## 1. Получить Telegram API credentials

1. Зайди на https://my.telegram.org/apps под своим номером телефона (придёт код в Telegram).
2. Заполни форму создания приложения (App title / Short name — можно любые, например `vacancies-export`; URL можно оставить пустым).
3. После создания получишь **App api_id** и **App api_hash** — это твои личные ключи доступа к Telegram API, никому их не показывай и не публикуй.

## 2. Установка

```bash
cd telegram-vacancies
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и впиши свои `TG_API_ID`, `TG_API_HASH` и `TG_PHONE` (номер в формате `+79991234567`, привязанный к твоему Telegram-аккаунту — скрипт работает от твоего личного аккаунта, а не от бота, иначе история чатов не читается).

## 3. Список чатов

Открой `chats.txt` и впиши туда чаты, которые нужно выгрузить — по одному на строку:
- юзернейм публичного канала/чата: `@marketing_jobs_ru`
- ссылка-приглашение на закрытый чат: `https://t.me/+AbCdEfGhIjKlMnOp`

Чат должен быть тебе доступен (ты состоишь в нём на своём аккаунте) — иначе Telegram не даст прочитать историю.

## 4. Запуск

```bash
python export_vacancies.py
```

При первом запуске Telegram пришлёт код подтверждения в приложение — введи его в терминале (и пароль двухфакторки, если она включена). Дальше сессия сохраняется в файл `vacancies_session.session`, повторно код вводить не понадобится.

Скрипт напечатает прогресс по каждому чату и сохранит результат в `raw_marketing_vacancies.csv`:

| chat | chat_title | date | poster_contact | link | text | matched_marketing_keywords | matched_vacancy_keywords |
|---|---|---|---|---|---|---|---|

Это "сырая" выгрузка — она однозначно извлекает то, что видно в Telegram напрямую (чат, дата, автор сообщения, ссылка, текст). Роль, компанию, гео и контакт для отклика надёжно регуляркой из свободного текста вакансий не вытащить — это делает Claude на следующем шаге.

## 5. Финальная таблица

Пришли файл `raw_marketing_vacancies.csv` (или его содержимое) обратно в чат — на основе текста каждой вакансии будут добавлены поля «роль», «компания», «гео», «контакт в посте» (контакт для отклика, указанный в тексте объявления — он может отличаться от `poster_contact`, автора самого сообщения) и «reasoning» (почему сообщение классифицировано как маркетинговая вакансия), после чего готовая таблица прикладывается файлом.

## Как настроить фильтры

- Диапазон дат — переменные `TG_START_DATE` / `TG_END_DATE` в `.env` (формат `YYYY-MM-DD`).
- Ключевые слова — списки `VACANCY_KEYWORDS` и `MARKETING_KEYWORDS` в `config.py`. Сообщение попадает в таблицу, если содержит хотя бы одно слово из **каждого** списка (это отсекает вакансии не по маркетингу и обсуждения маркетинга без вакансий). Дополняй списки своими словами при необходимости.

## Безопасность

- `.env` и `*.session` — не коммитить в git (уже добавлены в `.gitignore`), в них живут твои личные credentials и авторизованная сессия аккаунта.
