# Intake checklist

Work through one group at a time. Tick off only after verification.

- [ ] 1. Code package (stage 1-3 files copied unmodified, missing files reported)
- [ ] 2. Reference images in refs/ (3-4 images, each opened and described)
- [ ] 3. Logo, optional (SVG or PNG, white and dark variants, in assets/)
- [ ] 4. Keys (.env.example and .gitignore created; owner creates .env locally)
- [ ] 5. Decisions (audience time zone, publish time, written to config.yaml)
- [ ] 6. Optional inbox seed (1-3 urgent or fresh topics in inbox/inbox.json)

## Final steps (Step D)
- [ ] virtualenv + requirements installed
- [ ] tests pass
- [ ] `python scripts/build_plan.py --dry-run` runs
- [ ] git init + first commit
